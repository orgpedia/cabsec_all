Here are the issue codes, described in old/new terms. The words mean:

- old: the consolidated version printed before the amendment, e.g. 1_Upload_883.pdf.
- amendment: the notification for Series N, e.g. 1_Upload_367.pdf (Series 322).
- new: the consolidated version printed after it, e.g. 1_Upload_884.pdf.
- expected new: what we get when we apply the amendment to old.
- states: the Rules built up from the start (Series 301) by applying every amendment in turn, without using the printed versions in between. In Phase C, where there are no versions in between, this is the only chain we'll have.
